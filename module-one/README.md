# Capture and model tools

These standalone tools support development and measurement; use the [main README](../README.md) to build the app.

- [capture](capture/README.md): bounded microphone recording and retry-audio checks.
- [session](session/README.md): shortcut-driven capture and local transcription with durable text recovery.
- [models](models/README.md): pinned artifact verification, the ModelBench helper and benchmark tooling.

Use synthetic or consented test content. Keep recordings, transcripts and raw benchmark output outside Git. Tool checks do not establish live app reliability, speech accuracy or physical-key first-word preservation.
