# Murmur 0.2.0 — unsigned preview

Murmur can now check GitHub for updates, verify signed downloads, and install updates from inside the app. Automatic installation is optional and off by default. Updates wait for dictation, meeting recording, final transcription, speaker separation, and notes writing to finish. [Certain]

This preview uses a local development signing identity, not Apple Developer ID, and is not notarized. macOS Gatekeeper may block the first launch; only proceed if you trust this project's download. Sparkle's update signature authenticates updates but does not remove this macOS warning. [Certain]

If your current build has no Sparkle updater, manually install this version once; later updates can use Sparkle. The stable update feed becomes available when this release is published. [Certain]

Requires Apple silicon and macOS 26 or later. [Certain]
